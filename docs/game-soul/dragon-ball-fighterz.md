# Dragon Ball FighterZ — Heart and Soul
- Developer / studio: Arc System Works; published by Bandai Namco (producer Tomoko Hiroki; director Junya Motomura)
- Genre / platforms: 3v3 anime fighting game / PS4, Xbox One, PC (Steam), Switch, PS5/XSX (later)
- Why players come back (in the devs' view): The explicit, stated mission was to unite two communities — Dragon Ball fans and fighting-game fans — by moving depth from execution into "mind games" and strategy. Producer Tomoko Hiroki's design philosophy: simplify the button layout so beginners can button-mash and veterans still get a "truly competitive game when fully utiliz[ing] all battle features." The 2D anime-style presentation was chosen for spectatability: "it's really easy for people to consume, be an audience for, and spectate." Long-term retention came from treating it as a live esports platform (World Tour, balance patches that "deliver users a fresh experience"), plus fan-listening (the Switch port was made because fans demanded it).
- Key quotes:
  - "We thought that, rather than make the controls more and more difficult, we wanted to focus more on mind games, making each of the characters quite different." — Tomoko Hiroki, Producer, Eurogamer interview (via Nintendo Life, 2018)
  - "Our approach starts by determining our targets: which were Dragon Ball game fans and fighting game fans. The team's aim on this project was to merge the elements of character games and fighting games, and then create a game that would cater to both parties. One way to achieve that was by trying to simplify the button layout (command)—making it easier for fighting game beginners, while adding the strategizing element for veteran fighting game players at the same time." — Tomoko Hiroki, Producer, Fanatical interview (2018)
  - "One of our big goals is to have those Dragon Ball casual fans realize how fun a genuine fighting game can be through this game. And we want eventually, those guys, to become actual fighting game users. So that's where this project all began." — Tomoko Hiroki, Producer, Game Informer interview (via PlayStation LifeStyle, 2017)
  - "I think it's really easy for people to consume, be an audience for, and spectate... We took really good elements in the eSports space — 2D fighting games obviously are a huge element of eSports — and Dragon Ball, which is of course a really great platform I think for which 2D fighting game tournaments can be held on. So we tried to merge these two elements that were really a match made for each other." — Tomoko Hiroki, Producer, E3 2017 Twitch interview (via Christian Post, 2017)
- Why players love/support it: It finally delivered the "play the anime" fantasy (reproducing the *memory* of the anime, per Hiroki's "reproducing the memory that the user has in their mind" art direction); the 3v3 team format honors power disparities (Hiroki: "it would feel a bit odd to see [...] Goku being defeated by Krillin"); rollback added later; 8M+ copies sold on franchise love + esports presence.
- Monetization philosophy (devs' words, if any): Premium game + character season passes; monetization is character-driven (more of the anime's roster) — every season sold because players *love the characters*, and balancing updates were framed as "delivering users a fresh experience" (renewing the whole game each season).
- Lesson for our games (1-2 lines, concrete): Build the game to be *watched* — easy-to-read mechanics and named systems (Z Change, Super Dash) turn casual viewers into players. Put depth in decision-making, not in input difficulty; let button-mashers and competitors both play in the same room.
