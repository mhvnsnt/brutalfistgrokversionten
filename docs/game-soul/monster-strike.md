# Monster Strike — Heart and Soul
- Developer / studio: mixi (publisher), game design by Yoshiki Okamoto (Street Fighter II producer), producer/director Koki Kimura. (Kimura later became MIXI CEO.)
- Genre / platforms: Co-op action RPG (pinball/slingshot physics brawler); iOS + Android (2013 JP; $7B+ lifetime revenue; Western versions later shut down).
- Why players come back (in the devs' view): It was built from the ground up as a communication tool — the game is an excuse for friends to gather in the same room again. Local 4-player co-op is "the crux of the game." Short arcade-style sessions (5–10 min) match people's real lives, and rotating time-limited events "bring the community together all at one time." Crucially, the strongest monsters drop from co-op events, not the gacha — so you come back to play with friends, and friends pull weaker players up.
- Key quotes:
  - "The thing about Monster Strike is that it was built from the ground up, by us, to be a communication tool — to get people playing games together in the same room again." — Koki Kimura, producer/director (mixi), GameDeveloper/Gamasutra interview, 2014
  - "The skills that I learned making arcade games... Really making it fun in short bursts is really the big thing." — Yoshiki Okamoto, game designer (ex-Capcom), GameDeveloper/Gamasutra interview, 2014
  - "What I really enjoy about making mobile games is that you're much closer to the user... the events have to be played in the time that they're available — so it brings the community together all at one time... you can actually make real-time changes based on this feedback." — Yoshiki Okamoto, GameDeveloper/Gamasutra interview, 2014
  - "The local multiplayer is really the crux of the game... Monster Strike was the first game to come around to enable users to use their smartphones to play the same game together at the same time." — Koki Kimura, GameDeveloper/Gamasutra interview, 2014
- Why players love/support it: Face-to-face social play; co-op continues are cheaper than solo (one continue revives everyone), so monetization literally funds togetherness; gacha pulls are a shared experience — "if one of your friends gets a really strong monster, you're happy for them"; friends' strong monsters "pull your characters up." ANALYSIS (Kimura): strongest units come from rotating event drops, not the Hatcher, so free players can earn the best gear by playing.
- Monetization philosophy (devs' words, if any): Kimura on co-op continues: when you're playing alone you'll spend your own continue; with four players "it takes one continue for everyone to keep going. So it makes it cheaper... only one person has to make that sacrifice." On gacha fairness: "In a way, it's not unfair between players, because it's just pure luck for everyone... You can make a lot of money with a free-to-play game, but I feel there are still ways to grow how you do it, to make it interesting, fun, and ethical, even." (GameDeveloper/Gamasutra, 2014)
- Lesson for our games (1-2 lines, concrete): Make the game a communication tool — design co-op rewards that make playing WITH friends cheaper and stronger than solo. Put the best loot behind group events, not the paid gacha; shared pulls and shared wins build the community that retains.
